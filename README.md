# The Witcher — Arabic Guide

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-qibzdhzv)

An interactive Arabic companion guide to the world of The Witcher — covering the story, characters, kingdoms, monsters, magic, and lore, explained in chronological order for newcomers.

![Home Page](docs/home.png)

## Features

- **Full Arabic content** — everything written natively in Arabic, right-to-left layout
- **Story walkthrough** — the novels and the first two games, in chronological order
- **Character profiles** — Geralt, Yennefer, Ciri, Emhyr, and more
- **World & kingdoms** — the Continent, its history, races, and major realms
- **Monster bestiary** — weaknesses and combat strategies
- **Magic & glossary** — Chaos, Signs, alchemy, and a full terminology reference
- **Search & navigation** — fast in-app search, breadcrumbs, and reading progress

![Sections](docs/sections.png)

| Page | Description |

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** for build tooling
- **Tailwind CSS** for styling
- **Lucide React** for icons

## Getting Started

```bash
npm install
npm run dev
```

Then open the local dev URL in your browser.

## Build

```bash
npm run build
```
